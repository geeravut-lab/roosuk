# Fonts

`NotoSansThai-Regular.ttf` and `NotoSansThai-Bold.ttf` are Noto Sans Thai (Google / Noto Project),
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). They are used only to
draw the share-card images on the server (`src/lib/share/render.tsx`); the web app itself loads the
same family through `next/font/google`.
